Implemented fixed-point neural network inference on an STM32F042 microcontroller, optimizing inference time from 305 µs to 15.75 µs (19× speedup) while reducing flash usage by 64% and RAM usage by 43%.

**[SpheriCity — Retrieval-Augmented AI](https://github.com/samir299792/sphericity)**

A Flask/React RAG application using FAISS vector retrieval to answer questions grounded in sustainability assessment reports. Includes automated evaluation and benchmarking workflows.

**[Schedulo — Full-Stack Scheduling Application](https://github.com/samir299792/Schedulo)**

A meeting scheduling application built with React, Node.js, Prisma ORM, and OAuth, featuring customizable booking links, calendar integration, and scheduling conflict detection.
